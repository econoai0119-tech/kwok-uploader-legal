Kwok Uploader

Kwok Uploader is a personal, single-user desktop tool used by one independent creator to publish original animated short videos of the character "Kwok" (an animated quokka) to the creator's own YouTube, TikTok and Instagram accounts.

How it works

  • The creator signs in once with Google (OAuth 2.0, youtube.upload scope only), TikTok (Login Kit) and Instagram.
  • The tool uploads a finished MP4 to the creator's own channel using the YouTube Data API (videos.insert) and the TikTok Content Posting API.
  • It does not read, download or analyze other users' content, and it is not offered to the public.
